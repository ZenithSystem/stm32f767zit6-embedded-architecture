# Modulo 05 — Timer & PWM Generation

## Obiettivo Tecnico
Timer Basic (TIM6/7), General-Purpose (TIM2-5) e Advanced Control (TIM1/8) con Dead-Time e Input Capture.

## Struttura Pianificata
* `src/` — Implementazione Bare-Metal (CMSIS) e driver HAL
* `inc/` — Header file e interfacce pubbliche
* `notes/` — Calcoli dei registri, diagrammi temporali e misure all'oscilloscopio / logic analyzer
