# Zephyr RTOS — Prototipazione Avionica (`nucleo_f767zi`)

Spazio dedicato ai prototipi basati su **Zephyr RTOS** per applicazioni avioniche su **STM32F767ZIT6**:

* Gestione multi-thread real-time per acquisizione sensori, stima d'assetto e telemetria.
* Configurazione hardware tramite file DeviceTree overlay (`boards/nucleo_f767zi.overlay`) e `prj.conf`.
* Compilazione e flashing tramite `west build -b nucleo_f767zi` e `west flash`.
